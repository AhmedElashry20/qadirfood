### ١. تسجيل الدخول
إيميل/جوال + كلمة مرور · نسيت كلمة المرور · اختيار الفرع لو الحساب متعدد الفروع.

### ٢. الطلبات الواردة — قلب التطبيق ⭐
أهم شاشة، وتاخد أعلى جهد UX.
- قائمة الطلبات الجديدة **لحظياً** (`order:new`) مع **صوت تنبيه**.
- كارت الطلب: رقم الطلب · الأصناف · الملاحظات · قيمة الطلب · وقت الورود.
- زرّي **قبول** / **رفض** (الرفض بسبب إلزامي).
- **عداد زمني** لكل طلب جديد.
- **صوت التنبيه يفضل شغال لحد ما الطلب يتقبل أو يترفض** — مش مجرد نغمة واحدة.
- **حالة Offline واضحة**: لو النت قطع → بانر تحذير كبير + إشعار للأدمن.

### ٣. قبول الطلب + وقت التحضير
بعد ضغط «قبول»: اختيار وقت التحضير المتوقع (١٠ / ١٥ / ٢٠ / ٣٠ دقيقة أو مخصص).
ده اللي بيحدد **توقيت إرسال الكابتن** — راجع [دورة حياة الطلب](01-order-lifecycle.md).

### ٤. الطلبات الجارية
أعمدة أو تابات: `قيد التحضير` → `جاهز` → `في انتظار الكابتن` → `تم الاستلام`.
لكل طلب: بيانات الكابتن المسند (اسمه وموقعه).

### ٥. الطلب جاهز للاستلام
زر «جاهز» يغيّر الحالة ويبلّغ الكابتن · عرض **كود/رقم الطلب** للمطابقة مع الكابتن عند التسليم.

### ٦. سجل الطلبات
كل الطلبات المنتهية والملغاة · فلاتر (تاريخ / حالة) · تفاصيل أي طلب · أسباب الإلغاء.

### ٧. إدارة المنيو
التصنيفات (مقبلات / رئيسي / مشروبات…) · **سحب وإفلات** للترتيب · بحث في الأصناف · حالة كل صنف (متاح / موقوف) ظاهرة مباشرة.

### ٨. إضافة / تعديل صنف
الاسم (عربي/إنجليزي) · الوصف · الصورة · السعر · التصنيف · **مجموعات الخيارات والإضافات** (حجم، إضافات بسعر، اختيار إجباري/اختياري، حد أقصى) · السعرات (اختياري).

### ٩. إتاحة / إيقاف صنف (نفد المخزون)
**Toggle** سريع لأي صنف أو مجموعة أصناف · خيار «**إيقاف حتى نهاية اليوم**» (يرجع تلقائي) أو «**إيقاف دائم لحد ما أرجّعه**».

### ١٠. أوقات العمل
جدول أسبوعي (من/إلى لكل يوم) · **فترات متعددة في اليوم** (صباحية/مسائية) · أيام الإجازة · مواعيد رمضان.

### ١١. فتح / إغلاق المطعم (Busy Mode)
زر رئيسي واضح: **مفتوح** / **مغلق مؤقتاً** / **مشغول**.
وضع «مشغول» بيزوّد وقت التحضير تلقائياً ١٥–٣٠ دقيقة طول ما هو شغال.

### ١٢. التقارير والمبيعات
مبيعات اليوم/الأسبوع/الشهر · عدد الطلبات · متوسط قيمة الطلب · الأصناف الأكثر مبيعاً · معدل الرفض/الإلغاء · **التسويات المالية** (المستحق بعد العمولة + تواريخ التحويل).

### ١٣. الإعدادات والملف
بيانات المطعم (لوجو، وصف، تواصل) · إدارة الفروع · مستخدمي الفرع (كاشير/مدير) · الإشعارات (صوت التنبيه ومستواه) · تغيير كلمة المرور · الدعم.
