# أصوات التنبيه

## المطلوب: `new_order.mp3`

**لازم تحط ملف صوت باسم `new_order.mp3` في المجلد ده بالظبط.**

```
apps/merchant_app/assets/sounds/new_order.mp3
```

من غير الملف ده، `SoundService` هيفشل بهدوء (بيتعامل مع الخطأ ويسجّله) والتطبيق هيشتغل عادي — بس **من غير صوت تنبيه للطلبات الجديدة**، وده أهم feature في شاشة الطلبات الواردة.

## مواصفات الملف

| الخاصية | القيمة الموصى بيها |
|---|---|
| الصيغة | MP3 |
| المدة | ٢ – ٤ ثواني |
| الطابع | نغمة تنبيه واضحة وحادة (مطبخ فيه دوشة) |
| الحجم | أقل من ١٠٠ كيلوبايت |
| الصوت | Mono أو Stereo، 44.1kHz |

## إزاي بيشتغل

`lib/core/sound_service.dart` بيشغّل الملف بـ **`ReleaseMode.loop`** — يعني بيفضل **مكرر من غير توقف** طول ما فيه طلب واحد على الأقل حالته `PENDING`.

الصوت بيقف **بس** لما:
- كل الطلبات الواردة تتقبل أو تترفض (عدد الطلبات `PENDING` يبقى صفر)، أو
- المستخدم يضغط زر «كتم مؤقت» (بيرجع يرن لو جه طلب جديد)

عشان كده المدة قصيرة أحسن — الملف بيتلوّب على طول.
